Research Motivation

The Critical Failure Modes of Modern Vision Classifiers

1. Train-Inference Divergence

  • Real-world user canvas strokes differ drastically from curated benchmark tensors.
  • Off-center drawings, stroke thickness variations, and inverted backgrounds cause catastrophic inference collapse.
  • Absence of a shared, invariant canonical preprocessing pipeline guarantees silent production failures.

2. Overconfident Black-Box Decisions

  • Standard Softmax outputs are uncalibrated and overconfident on corrupt or out-of-distribution inputs.
  • Classifiers routinely emit >99% confidence on blank canvases, partial scribbles, or random noise.
  • Lack of epistemic uncertainty estimation (entropy, margin) makes automated delegation hazardous.

3. Opaque Attribution

  • Auditors and end-users receive scalar class labels without spatial justification.
  • No mechanism to verify whether the model attended to genuine anatomical digit strokes or border artifacts.
  • Demands real-time Explainable AI (Grad-CAM and Saliency maps) coupled directly to forward inference.

Objective 01: Canonical Preprocessing Invariant

Engineer a single, authoritative preprocessing pipeline shared identically between offline training, validation, and real-time live canvas inference. Guarantees contrast normalization, bounding box detection, aspect-ratio scaling into a 20×20 box, and spatial moment centering to (13.5, 13.5).

Objective 02: Multi-Model Empirical Benchmark

Establish a comparative evaluation matrix across 5 distinct model paradigms (Deep ConvNet, LeNet-5, SVM RBF, Random Forest, Logistic Regression) evaluated on an isolated 10,000-sample test set with zero data leakage.

Objective 03: Input-Quality Intelligence & Gating

Construct a pre-inference quality gatekeeper that audits stroke density, bounding box coverage, centroid deviation, and noise ratio before model invocation, failing closed on malformed drawings.

Objective 04: Real-Time Explainability & Telemetry HUD

Integrate dual-stream visual attribution (Grad-CAM at layer conv_cam and gradient saliency) into the live forward pass, accompanied by Shannon entropy, margin metrics, and diagnostic telemetry.

Core System Invariant

The 10-Stage Canonical Preprocessing Invariant

Sequential Pipeline Specification

  1. Multi-Format Decoding: Raw Base64 / Bytes / PIL → Grayscale.
  2. Contrast Normalization: Corner-sample test; inverts dark-on-light to white-on-black.
  3. Foreground Binarization: Fixed threshold (tau=25) or Otsu adaptive selection.
  4. Tight Bounding Box: Coordinates (x, y, w, h). If active < 8 px, fails closed.
  5. Aspect-Preserving Resize: Scaled into 20×20 inner box (cv2.INTER_AREA).
  6. Canvas Placement: Positioned in 28×28 zero canvas.
  7. Spatial Moments: Computes m00, m10, m01 center-of-mass (x_c, y_c).
  8. Centroid Translation: Affine warp shifts center-of-mass to (13.5, 13.5).
  9. Range Normalization: Clipped to [0.0, 1.0] float32.
  10. Tensor Reshaping: Strict (1, 28, 28, 1) float32 output.
